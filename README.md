# 🌐 Volkshub Website

Official landing page for **Volkshub**, a corporation focused on innovation, design, and infrastructure.  
This repository contains the **frontend website** and its **supporting pages** (Marketing, Creative, Projects).

---

## 📁 Structure

/
├── index.html # Landing page
├── marketing.html # Head of Marketing section
├── creative.html # Head of Creative Design section
├── projects.html # Project listings
├── /css
│ └── style.css # Main stylesheet


---

## 🚀 Features

- **Modern and responsive** landing page
- Modular page design for easy expansion
- Templates for:
  - Head of Frontend Design & Infrastructure
  - Head of Marketing
  - Head of Creative Design
- Dedicated **Projects page** showcasing Volkshub projects
